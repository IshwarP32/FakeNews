Project Plan

Fake News Risk Analyzer

Problem Statement

Misinformation spreads quickly and creates confusion, fear, and social disruption.

Most systems only classify news as true or false, but they do not measure how harmful or risky it may be.

Project Idea

This project analyzes news content, checks for suspicious patterns, and assigns a risk score based on source reliability, emotional tone, urgency, and topic sensitivity.

It also explains the result using AI-assisted evidence to make the decision understandable and useful in real situations.

High-Level Design
1. Input News title/article/url
→
2. Preprocess Clean text and extract features
→
3. Risk Analysis Source, tone, urgency, keywords, and severity scoring
→
4. AI Evidence Explain result using trusted-source context
→
5. Output Risk level with reasons and evidence summary

Project Plan

1 – Problem Definition: Finalize the project goal, define the core problem, and identify the target use case for misinformation risk detection.
2 – Dataset and Baseline: Collect relevant news data, review the Kaggle fake/real news dataset, and build a baseline classifier to understand the text patterns.
3 – Preprocessing and Feature Design: Clean the text, remove noise, and extract linguistic and content-based features such as sentiment, urgency cues, and suspicious language.
4 – Risk Engine Development: Develop the risk-scoring logic to evaluate source reliability, emotional tone, topic sensitivity, and misinformation severity.
5 – Backend and Database Integration: Build the backend services, connect the application to the database, and store analyzed articles, scores, and explanations.
6 – AI Evidence Layer: Integrate a GenAI API to provide evidence-based reasoning and explain the risk score in a user-friendly way.
7 – System Testing and Refinement: Test the full workflow, correct model or logic issues, improve result quality, and ensure the application behaves consistently.
8 – Final Demo and Documentation: Prepare the final demo, verify the end-to-end flow, and document the project outcomes and results for presentation.

Requirements to Learn Before Starting

Must Learn:

  • Python basics and data handling
  • Text preprocessing for NLP: cleaning, tokenization, stop words, stemming/lemmatization
  • Basic ML for text classification: logistic regression, Naive Bayes, TF-IDF
  • REST API basics with Flask or FastAPI
  • Working with JSON, request/response handling, and backend integration
  • How to call GenAI APIs and design prompts
  • Basic database operations with SQLAlchemy or SQL models
  • Frontend basics in React for a simple dashboard

Recommended:

  • Sentiment analysis and keyword-based feature extraction
  • Evaluation metrics: accuracy, precision, recall, F1-score
  • How to handle model outputs and display them in a web app
  • Basic deployment understanding for local demo or hosting

Optional:

  • Vector search or retrieval-based evidence lookup
  • Advanced prompt engineering for better AI explanation
  • Topic modeling or clustering for deeper analysis

This keeps the project practical and avoids learning too much unrelated technology. The goal is to learn only the minimum needed to build a strong, working solution.
